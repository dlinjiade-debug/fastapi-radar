## Personal contribution

- Added a CSV export path for the filtered request list in the dashboard.
- Added CSV escaping for commas, quotes, line breaks, and empty values.
- Added safe, cross-platform export filenames and UTF-8 BOM support for spreadsheet tools.
- Added accessible labels and disabled states for JSON and CSV export actions.

This fork documents the changes above. It does not claim authorship of the original
FastAPI Radar project.
